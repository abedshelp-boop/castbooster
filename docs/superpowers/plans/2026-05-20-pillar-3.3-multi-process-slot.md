# Pillar 3.3 — Multi-Process `_ProcessSlot` Implementation Plan

> **For agentic workers:** Use `superpowers:subagent-driven-development`
> (recommended) or `superpowers:executing-plans` to implement this plan
> task-by-task. Steps use `- [ ]` checkbox syntax for tracking.

**Goal:** Teach `_ProcessSlot` to spawn the "1 encode ffmpeg + 1 side
task Thread (which manages N inner subprocesses internally)" topology
that P3.2's `RIFEFilter` produces via `PipelineSpec`. After P3.3 lands,
the transcoder can hot-reload `NoopFilter ↔ RIFEFilter` mid-cast.

**Branch:** `pillar-3.3/multi-process-slot`, cut from master (commit
`bad9089` — the P3.2 merge). Baseline test count: **260 passed + 6
skipped**. Target after P3.3: **278 passed + 6 skipped** (+18 new M-*
tests).

**Architecture:** `_ProcessSlot.start(argv, pipeline_spec=None)`
branches. When `pipeline_spec is None`, today's single-Popen path runs
unchanged. When non-None, `_spawn_pipeline` spawns encode ffmpeg
(stdin=PIPE, **bufsize=0**, stderr=PIPE), then launches the side task
on a `threading.Thread` running `_side_task_wrapper(factory, ctx)`. The
wrapper catches `BrokenPipeError → idle_reason="encoder_died"` and all
other exceptions `→ idle_reason="side_task_crashed"`. Watchdog poller
also checks `side_task_thread.is_alive()` for the
"returned-early" path. Brainstorm decisions Q1/Q2/Q3 are locked.

**Tech Stack:** Python 3.11+, pytest, `subprocess.Popen`,
`threading.Event`, `threading.Thread`. No new dependencies.

  ```python
  # near other module constants
  _BASE_BITRATE_BPS = 3_000_000  # matches HW-encoder `-b:v 3M` in _ENCODER_FLAGS


  def _scaled_bitrate(base_bps: int, src_fps: float, tgt_fps: int) -> int:
      """sqrt scaling per parent P3 spec D6: new = base * sqrt(tgt/src).

      Examples:
          24 -> 60: ratio sqrt(60/24) ≈ 1.58
          24 -> 30: ratio sqrt(30/24) ≈ 1.12
      """
      import math
      return int(base_bps * math.sqrt(tgt_fps / max(src_fps, 1.0)))


  def _parse_encoder_input_format(spec: str) -> tuple[str, str]:
      """rawvideo:yuv420p:1920x1080 → ("yuv420p", "1920x1080").

      Raises ValueError on malformed input. Only "rawvideo:..." is
      supported in P3.3 (P4 may add more).
      """
      parts = spec.split(":")
      if len(parts) != 3 or parts[0] != "rawvideo":
          raise ValueError(f"unsupported encoder_input_format: {spec!r}")
      return parts[1], parts[2]
  ```

  from castbooster.pipeline_spec import PipelineSpec

  def _spec_from_chain(chain: FilterChain) -> Optional[PipelineSpec]:
      """Return the first non-None pipeline_spec() in the chain, or None.

      Raises ValueError if more than one stage returns a non-None spec —
      P3.3 is YAGNI on multi-PipelineSpec chains; no real filter needs that yet.
      """
      spec: Optional[PipelineSpec] = None
      for stage in chain.stages:
          s = stage.pipeline_spec()
          if s is None:
              continue
          if spec is not None:
              raise ValueError(
                  "FilterChain has more than one stage returning a "
                  "PipelineSpec — not supported in P3.3"
              )
          spec = s
      return spec
  ```

  def _spawn_pipeline(self, encoder_argv: list[str], spec: PipelineSpec) -> None:
      from castbooster.pipeline_spec import SideTaskContext
      self._workdir = self._output_dir / "_workdir"
      self._workdir.mkdir(parents=True, exist_ok=True)

      creationflags = 0
      if sys.platform == "win32":
          creationflags = subprocess.CREATE_NO_WINDOW
      log.info("encode ffmpeg argv (multi-proc): %s", " ".join(repr(a) for a in encoder_argv))
      self._process = subprocess.Popen(
          encoder_argv,
          stdin=subprocess.PIPE,
          stderr=subprocess.PIPE,
          stdout=subprocess.DEVNULL,
          bufsize=0,                                # Q1 locked decision
          creationflags=creationflags,
      )
      log.info("encode ffmpeg PID=%s started (multi-proc)", getattr(self._process, "pid", "?"))
      self._warming_started_monotonic = time.monotonic()
      with self._sub_state_lock:
          self._set_sub_state_locked(_SlotState.WARMING)

      assert self._process.stdin is not None
      ctx = SideTaskContext(
          input_url=getattr(self, "_input_url_for_side_task", ""),  # set by Transcoder pre-start; see T9
          target_fps=spec.target_fps,
          encoder_stdin=self._process.stdin,
          workdir=self._workdir,
          cancel_event=self._side_cancel_event,
      )
      self._side_task_thread = threading.Thread(
          target=self._side_task_wrapper,
          args=(spec.side_task_factory, ctx),
          name=f"slot-side-task-{id(self):x}",
          daemon=True,
      )
      self._side_task_thread.start()

      self._poller_thread = threading.Thread(
          target=self._watchdog_poller_loop,
          name=f"slot-poller-{id(self):x}",
          daemon=True,
      )
      self._poller_thread.start()

      self._stderr_thread = threading.Thread(
          target=self._stderr_reader_loop,
          name=f"slot-stderr-{id(self):x}",
          daemon=True,
      )
      self._stderr_thread.start()
  ```

  def _side_task_wrapper(self, factory: Callable, ctx) -> None:
      try:
          factory(ctx)
      except BrokenPipeError as e:
          if ctx.cancel_event.is_set():
              return
          with self._sub_state_lock:
              if self._sub_state not in (
                  _SlotState.FAILED, _SlotState.TERMINATING, _SlotState.TERMINATED,
              ):
                  self._side_task_exception = e
                  self._set_sub_state_locked(_SlotState.FAILED, idle_reason="encoder_died")
      except BaseException as e:
          if ctx.cancel_event.is_set():
              return
          with self._sub_state_lock:
              if self._sub_state not in (
                  _SlotState.FAILED, _SlotState.TERMINATING, _SlotState.TERMINATED,
              ):

                  self._set_sub_state_locked(_SlotState.FAILED, idle_reason="side_task_crashed")

## Risks during implementation

- **Side-task Thread livelock on stop()**: the wrapper checks
  `cancel_event` at the start of each batch in RIFEFilter, but the
  stub `FakeRIFEFilter._default_side_task` should also check it in its
  blocking wait — otherwise tests will hang on `stop()`. Use
  `cancel_event.wait(timeout=...)` rather than a bare loop.
- **Encode-ffmpeg `bufsize=0`**: only the multi-proc encoder uses
  bufsize=0 (per spec). The single-Popen path stays at the existing
  default (-1). Tests must not assert bufsize on the single-proc
  fakes.
- **FakePopen vs side task race**: the existing `_FakePopenFactory`
  is sufficient — multi-proc Popen test setup needs ONE queued fake
  per slot (the encoder; side procs are invisible because they live
  inside the side task, which we replace with a controllable
  `FakeRIFEFilter`).
- **State enum coverage**: if a new transition emerges during
  implementation that isn't in §4, STOP and update the matrix.
