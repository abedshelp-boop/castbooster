## 1. Context

Pillar 2 evolves the castbooster proxy from a passthrough HLS rewriter into a
real-time HLS re-segmenter so RIFE (P3), Anime4K (P4), the watchdog (P5), and
the license gate (P6) all have a frame-level pipeline slot. P2.1 vendored
ffmpeg and shipped the `AccelProfile` probe (`app/castbooster/ffmpeg_probe.py`).
**P2.2 builds the worker that manages one ffmpeg subprocess per cast session.**

This sub-session ships:

- `app/castbooster/transcoder.py` — `Transcoder` class with an explicit state
  machine (IDLE → SPAWNING → WARMING → READY → STREAMING ↔ STALLED;
  TERMINATING → TERMINATED; FAILED). Per the 2026-04-22 IDLE-race lesson,
  every observable state (startup + transient + terminal) is enumerated and
  exercised by tests — **no predicate ever treats "not active = done"**.
- Output directory lifecycle: created on `start()`, deleted on `stop()`.
- Stderr parser producing structured `idle_reason` strings.
- 22 unit tests with mocked `subprocess.Popen`.
- 1 integration test gated on `RUN_REAL_FFMPEG=1` — lavfi-generated 5 s input,
  READY within 8 s.

P2.2 does **not** touch `proxy.py`, `caster.py`, or `session_store.py`. The
Transcoder is a leaf module that P2.4 will wire in.

## 2. Decisions locked in brainstorm (2026-05-15)

| # | Decision | Choice |
|---|---|---|
| C1 | **Threading model** | Sync threaded. Internal worker threads; blocking public API. Proxy calls via `loop.run_in_executor`, matching today's `cm.play` / `cm.get_status` pattern in [proxy.py](../../../app/castbooster/proxy.py). |
| C2 | **WARMING timeout** | Constructor parameter, default `8.0` s. Lets unit tests pass a tiny timeout to exercise FAILED without slowing CI; lets P2.6 tune it from real soak numbers. |
| C3 | **TERMINATING shutdown** | Graceful drain: write `q\n` to ffmpeg stdin (its documented clean-shutdown command, reliable on Windows where SIGTERM is flaky), wait up to `drain_seconds` (default `2.0`) for self-exit, then `process.kill()` as fallback. |
| C4 | **HLS segment length** | `-hls_time 2` (2 s segments). Fast READY: 2 segs = 4 s of source video. |
| C5 | **HLS list size** | `-hls_list_size 6` with `-hls_flags delete_segments+append_list+independent_segments`. Rolling 12 s retention; ffmpeg handles eviction. |
| C6 | **Master playlist** | Hand-written at `start()` (BANDWIDTH/RESOLUTION placeholders; refined in P2.5). ffmpeg writes only `variant.m3u8` for single-bitrate output, so we author `master.m3u8` ourselves to satisfy the parent plan's "master + variant" READY predicate. |
| C7 | **HW-encoder paths** | Code written for `h264_nvenc` / `h264_qsv` / `h264_amf` but labeled "untested-pending-hardware" per P2.1 B2. Abed's Snapdragon dev box exercises `libx264`. |
| C8 | **No new Python deps** | Stdlib only (`subprocess`, `threading`, `pathlib`, `shutil`, `re`, `enum`, `dataclasses`). |

## 3. Architecture

```
caller (P2.4 proxy / integration test / etc.)
   │
   │  loop.run_in_executor(None, transcoder.wait_until_ready, 8.0)
   ▼
┌──────────────────────────────────────────────┐
│ Transcoder (one per session)                 │
│                                              │
│   state: TranscoderState (Enum)              │
│   idle_reason: Optional[str]                 │
│   output_dir: Path                           │
│   _ready_event: threading.Event              │
│   _state_lock: threading.Lock                │
│                                              │
│   ┌──────────────┐    ┌────────────────────┐ │
│   │ stderr-rdr   │    │ watchdog-poller    │ │
│   │ thread       │    │ thread (250 ms)    │ │
│   │              │    │                    │ │
│   │ classifies   │    │ proc.poll() +      │ │
│   │ each line;   │    │ output_dir scan;   │ │
│   │ may set      │    │ drives state       │ │
│   │ FAILED       │    │ transitions        │ │
│   └──────┬───────┘    └─────────┬──────────┘ │
│          │                      │            │
│          ▼                      ▼            │
│   ┌──────────────────────────────────────┐   │
│   │  ffmpeg subprocess                   │   │
│   │  Popen(<argv>, stdin=PIPE,           │   │
│   │        stderr=PIPE, stdout=DEVNULL)  │   │
│   │  writes seg_NNNNN.ts + variant.m3u8  │   │
│   │  to output_dir                       │   │
│   └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

### 3.1 State table (parent-plan §5 + plain English)

| State | Means | Chromecast can fetch? |
|---|---|---|
| `IDLE` | Constructed; `start()` not yet called | NO |
| `SPAWNING` | `Popen` returned; pipes open; no log line yet | NO |
| `WARMING` | ffmpeg running, < 2 segs OR no `variant.m3u8` OR no `master.m3u8` | NO |
| `READY` | ≥ 2 `seg_*.ts` + `master.m3u8` + `variant.m3u8` on disk | YES |
| `STREAMING` | New segment appeared after READY (cadence healthy) | YES |
| `STALLED` | STREAMING but no new seg for `stall_timeout` (default 8 s) | YES (serve what we have) |
| `FAILED` | Subprocess exited non-zero OR stderr matched fatal pattern | NO |
| `TERMINATING` | `stop()` called; `q\n` sent; draining | NO |
| `TERMINATED` | Subprocess reaped, output dir deleted | NO |

**Invariants:**

- The **poller** is the ONLY component that promotes WARMING → READY
  (filesystem evidence). It is also the ONLY component that drives
  READY → STREAMING and STREAMING ↔ STALLED.
- The **stderr reader** is the ONLY component that promotes any state → FAILED
  via pattern match.
- The **poller** is the ONLY component that promotes pre-READY → FAILED via
  process-exit observation (`subprocess_died_early`), WARMING → FAILED via
  elapsed-time check (`warming_timed_out`), and post-WARMING → FAILED via
  post-exit non-zero (`unknown`).
- All state mutations go through a single `_set_state(new, idle_reason=None)`
  method under `_state_lock`.
- `_ready_event` (a `threading.Event`) is set the first time state becomes
  READY *or* FAILED, so `wait_until_ready()` blocks on it cleanly.

## 4. Public API

```python
from enum import Enum
from pathlib import Path
from typing import Optional

from castbooster.ffmpeg_probe import AccelProfile


class TranscoderState(Enum):
    IDLE = "idle"
    SPAWNING = "spawning"
    WARMING = "warming"
    READY = "ready"
    STREAMING = "streaming"
    STALLED = "stalled"
    FAILED = "failed"
    TERMINATING = "terminating"
    TERMINATED = "terminated"


class Transcoder:
    """Manages one ffmpeg subprocess that re-segments an input HLS source.

    See module docstring for the full state-machine contract.
    """

    def __init__(
        self,
        input_url: str,                  # ffmpeg -i target (HTTP URL or local file path)
        output_dir: Path,                # caller-chosen; typically %TEMP%/castbooster/<token>/
        accel: AccelProfile,             # from ffmpeg_probe.detect()
        warming_timeout: float = 8.0,    # WARMING budget before FAILED
        stall_timeout: float = 8.0,      # no-new-seg budget for STREAMING→STALLED
        hls_segment_seconds: int = 2,    # -hls_time
        _poll_interval: float = 0.25,    # private: tests pass smaller value
    ) -> None: ...

    # Read-only properties ----------------------------------------------------
    @property
    def state(self) -> TranscoderState: ...
    @property
    def idle_reason(self) -> Optional[str]: ...     # set when state == FAILED
    @property
    def master_playlist(self) -> Path: ...           # output_dir / "master.m3u8"
    @property
    def exit_code(self) -> Optional[int]: ...        # subprocess exit code once reaped

    # Lifecycle ---------------------------------------------------------------
    def start(self) -> None:
        """IDLE → SPAWNING → WARMING. Non-blocking. Spawns subprocess + threads.
        Raises RuntimeError if already started."""

    def wait_until_ready(self, timeout: Optional[float] = None) -> bool:
        """Block until READY (returns True) or FAILED/timeout (returns False).
        Default timeout = self.warming_timeout."""

    def stop(self, drain_seconds: float = 2.0) -> None:
        """TERMINATING flow:
          1. _set_state(TERMINATING)
          2. proc.stdin.write(b'q\\n'); proc.stdin.flush()
          3. proc.wait(timeout=drain_seconds) — if returns, we're cleanly out
          4. else proc.kill(); proc.wait()
          5. Join stderr-reader + watchdog-poller threads (with their own timeouts)
          6. shutil.rmtree(output_dir, ignore_errors=True) — retry once on Windows lock
          7. _set_state(TERMINATED) — preserves prior idle_reason if any
        Idempotent: calling twice is a no-op after the first."""
```

## 5. ffmpeg command construction

Built once at `start()` time from `self.accel` and the constructor args:

```
<accel.ffmpeg_path>
  -hide_banner -loglevel info -nostdin
  [-hwaccel <accel.decoder>]            # only if accel.decoder != "none"
  -fflags +genpts
  -i <input_url>
  -vf null                              # P2.3 will replace this string
  -c:v <accel.encoder> <encoder_flags>
  -c:a copy                             # P2.5 makes this smarter
  -f hls
  -hls_time <hls_segment_seconds>
  -hls_list_size 6
  -hls_flags delete_segments+append_list+independent_segments
  -hls_segment_filename "<output_dir>/seg_%05d.ts"
  "<output_dir>/variant.m3u8"
```

Per-encoder flag table (verify against current ffmpeg HLS muxer / encoder
docs via `context7` MCP at the start of the implementation session, per
Abed's CLAUDE.md rule #2):

| `accel.encoder` | Flags |
|---|---|
| `libx264` | `-preset veryfast -tune zerolatency -profile:v main -level 4.0 -pix_fmt yuv420p` |
| `h264_nvenc` | `-preset p5 -tune ll -profile:v main -rc cbr -b:v 3M` |
| `h264_qsv` | `-preset veryfast -profile:v main -b:v 3M` |
| `h264_amf` | `-quality balanced -profile:v main -b:v 3M` |

Subprocess is created with `stdin=PIPE`, `stderr=PIPE`, `stdout=DEVNULL`, and
on Windows `creationflags=subprocess.CREATE_NO_WINDOW` (matches the pattern
in `ffmpeg_probe._run`).

### 5.1 Master playlist (hand-written)

Written to `output_dir / "master.m3u8"` at `start()` before `Popen`:

```
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-STREAM-INF:BANDWIDTH=3000000,RESOLUTION=1280x720,CODECS="avc1.4d401f,mp4a.40.2"
variant.m3u8
```

BANDWIDTH / RESOLUTION / CODECS are P2.2 placeholders; P2.5's receiver-
capability probe refines them. Required so the READY predicate ("master +
variant on disk") can succeed.

## 6. Stderr classification

`_classify_stderr_line(line: str) -> Optional[str]` returns an `idle_reason`
token on a fatal-pattern match, else `None`. The reader thread acts on
non-None returns by calling `_set_state(FAILED, idle_reason=<token>)`.

| Regex (case-insensitive) | `idle_reason` |
|---|---|
| `No NVENC capable devices found` / `nvenc.*not supported` | `hwaccel_unavailable` |
| `Cannot load (libcuda\|nvcuda)` | `hwaccel_unavailable` |
| `qsv.*not (supported\|available)` | `hwaccel_unavailable` |
| `Connection refused` / `404 Not Found` / `HTTP error 4\d\d\|5\d\d` | `input_unreachable` |
| `Invalid data found when processing input` | `input_unreachable` |
| `Error.*opening encoder` / `Cannot initialize.*encoder` / `Failed to open codec` | `encoder_init_failed` |

Plus two compounds emitted by the **poller** when it observes process exit:

- `subprocess_died_early` — process exited pre-READY and no stderr pattern hit
- `unknown` — process exited non-zero post-WARMING and no stderr pattern hit
- `warming_timed_out` — set when `warming_timeout` elapses without READY

The list is intentionally small. Extending it is a one-line append in P2.6
once we have a corpus of real failures from the 30 min soak test.

## 7. Output directory lifecycle

| Moment | Action |
|---|---|
| `__init__` | Store `output_dir`. No I/O. |
| `start()` (pre-Popen) | `output_dir.mkdir(parents=True, exist_ok=True)`; write `master.m3u8`. |
| Running | ffmpeg writes `seg_NNNNN.ts` + updates `variant.m3u8`. `-hls_flags delete_segments` + `-hls_list_size 6` auto-evicts old segs. |
| `stop()` after reap | `shutil.rmtree(output_dir, ignore_errors=True)`. If first attempt fails (Windows file lock), wait 500 ms and retry once. Give up after that — `%TEMP%` is OS-cleaned. |
| Crash (FAILED) | Same cleanup runs from the poller when it detects exit. |

The Transcoder owns its subdir only — it never deletes the parent
`%TEMP%\castbooster\` itself.

## 8. Tests

### 8.1 Unit tests — `app/tests/test_transcoder_lifecycle.py`

**Strategy:** `unittest.mock.patch("subprocess.Popen")` returns a
`FakeFfmpegProcess` we drive from the test. Each test manipulates the fake
(queue stderr lines, set exit code, accept stdin) AND directly touches files
in the output directory; the poller picks up the changes. Tests pass a small
`_poll_interval` (e.g. `0.05`) to keep CI fast.

`FakeFfmpegProcess` API:

- `.stdin` — `io.BytesIO`-backed sink; records every byte written
- `.stderr` — iterator yielding queued bytes; blocks until told to close
- `.poll()` — returns `None` until `.set_exit(code)` is called
- `.wait(timeout=None)` — blocks until exit, respects timeout
- `.kill()` — sets exit code to -9 if not already exited
- `.set_exit(code)` — schedules clean exit
- `.queue_stderr(line)` — adds a line for the reader thread to consume

**Coverage (22 tests — every state is exercised):**

| # | Test | Transition / contract |
|---|---|---|
| 1 | `test_initial_state_is_idle` | construct → IDLE |
| 2 | `test_start_transitions_to_spawning_then_warming` | start() → SPAWNING → WARMING |
| 3 | `test_warming_to_ready_when_files_appear` | touch 2 segs + variant → READY |
| 4 | `test_warming_to_failed_on_timeout` | tiny warming_timeout → FAILED + `warming_timed_out` |
| 5 | `test_warming_to_failed_on_stderr_nvenc_pattern` | "No NVENC capable devices" → FAILED + `hwaccel_unavailable` |
| 6 | `test_warming_to_failed_on_stderr_input_pattern` | "404 Not Found" → FAILED + `input_unreachable` |
| 7 | `test_warming_to_failed_on_early_exit` | fake exits 1 pre-READY, no pattern → FAILED + `subprocess_died_early` |

### 8.2 Integration test — `app/tests/test_transcoder_e2e.py`

Gated on `RUN_REAL_FFMPEG=1` (mirrors P2.1's pattern).

Steps:

1. Use the vendored ffmpeg to generate a 5 s 320×240 lavfi-sourced HLS file
   in `tmp_path/src/` (testsrc video + 440 Hz sine audio, `-hls_time 1`,
   `-hls_list_size 0`).
2. `Transcoder(input_url=str(src/"master.m3u8"), output_dir=tmp_path/"out",
   accel=ffmpeg_probe.detect())`, then `start()`.
3. Assert `wait_until_ready(timeout=8.0) is True`.
4. Assert `state in {READY, STREAMING}`.
5. Assert `master.m3u8` + `variant.m3u8` + ≥ 2 `seg_*.ts` exist in `output_dir`.
6. `stop()`; assert `state == TERMINATED` and `output_dir` does not exist.

Wall-clock budget: ~3–6 s on Abed's machine.

## 11. Risks & mitigations

| Risk | Mitigation |
|---|---|
| Test #4 (warming-timeout) is timing-sensitive on slow CI | Use `_poll_interval=0.05` and `warming_timeout=0.2`; tests run in well under 1 s |
| Stderr-reader thread blocks forever on a stuck pipe | The reader thread is a daemon; `stop()` doesn't depend on its exit. `Popen.wait()` reaps the OS resources. Worst case the daemon thread is GC'd at process exit. |
| Windows file lock prevents `rmtree(output_dir)` | Retry once after 500 ms; give up after that. `%TEMP%` is OS-cleaned. Logged at WARNING. |
| ffmpeg's `q\n` stdin-shutdown command differs across versions | P2.1 vendors a known build (Gyan 8.1). Behavior is verified by `test_stop_drains_via_stdin_q` (unit) and the integration test's `stop()` step. |
| Stderr fatal-pattern list is incomplete and real failures get classified as `unknown` | Acceptable for P2.2. Extension is a one-line append in P2.6 once we have soak-test corpus. |
| `subprocess.CREATE_NO_WINDOW` not present on non-Windows during dev | `ffmpeg_probe._run` already guards this with `sys.platform == "win32"`; the Transcoder uses the same pattern. |
