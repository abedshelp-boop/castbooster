## 1. Context

P2.2 shipped `Transcoder` with the full state machine
(IDLE → SPAWNING → WARMING → READY → STREAMING ↔ STALLED; TERMINATING →
TERMINATED; FAILED). It currently hard-codes `-vf null` at
[transcoder.py:122](../../../app/castbooster/transcoder.py:122).

P2.3 is the **rack we install before we have any cool tools**. It introduces a
`FilterChain` abstraction so:

- **P3** can plug in `RIFEFilter` (frame interpolation) as one stage.
- **P4** can plug in `Anime4KFilter` (upscale + enhancement) as another stage.
- **P2.3 itself** ships only `NoopFilter` + `SubtitleBurnIn`. No visible
  enhancement; subtitle burn-in is the first real filter because it's the
  cheapest production-relevant filter to validate the abstraction (and it's
  the only one Pillar 2 needs per D2 of the parent plan).

It also adds **hot-reload**: `Transcoder.set_filter_chain(chain)` lets the
proxy / popup (P2.4+) swap filters mid-cast without dropping the session. A
new `RELOADING` state covers the short window when NEW ffmpeg is WARMING while
OLD is still STREAMING.

`RELOADING` is a direct application of the 2026-04-22 IDLE-race lesson: every
new state must be enumerated, popup polling must not classify a transient
"cast still alive" state as "cast ended". The table in §5 makes the per-state
gate explicit.

This sub-session ships ~150 lines of new module code, 13 unit tests for the
filter chain, 14 unit tests for RELOADING transitions, and 2 gated integration
tests. P2.4 will be the wiring session that exposes `set_filter_chain` through
the proxy.

## 2. Decisions locked in brainstorm (2026-05-15)

| # | Decision | Choice | Rationale |
|---|---|---|---|
| D1 | `NoopFilter.render()` output | Returns the string `"null"` | ffmpeg's documented passthrough filter — a single memcpy per frame, effectively free. Argv construction stays unconditional (`-vf <chain.render()>` always works). Forward-compatible with P3 SIGUSR1 reinit (filter graph exists in the running ffmpeg). Matches P2.2's current `-vf null`. |
| D2 | Filter scope | Filters own ONLY the `-vf` fragment | Transcoder keeps `_ENCODER_FLAGS` for `-c:v` flags. Clean separation: filter chain is "what to do per frame"; encoder is "how to compress". P3's fps change will trigger encoder retuning via a Transcoder-side hook, not a filter-owned flag. YAGNI on `encoder_hints()` until P3 needs it. |
| D3 | Hot-reload mechanism | **Spawn NEW, then kill OLD** | Start NEW ffmpeg in a fresh `<base>/v<N>/` dir. Wait until NEW reaches READY (its own warming_timeout). Atomically swap `_current → NEW`, kill OLD, rmtree OLD's dir. Worst-case Chromecast sees a brief seek-like pause when the playlist URL changes (P2.4's concern, not P2.3's). Clean fallback if NEW fails. SIGUSR1 in-place reinit is Unix-only — deferred to a P3 micro-task. |
| D4 | `SubtitleBurnIn` API | `SubtitleBurnIn(stream_index: int = 0)` | Renders `subtitles=<escaped_input_url>:si=<stream_index>`. Caller picks which embedded sub track. Default 0 means "first embedded track" — most anime sources. External `.srt` / `.ass` file support deferred to P2.5+. |
| D5 | New state name | `RELOADING` | Names the window where NEW is WARMING + OLD is still STREAMING. Popup polling MUST classify as "cast still alive" — explicit in §5 table. |
| D6 | Reload failure semantics | Keep OLD running, return `False` | If NEW never reaches READY (bad filter, missing sub track, encoder fail), kill NEW, rmtree NEW's dir, transcoder state returns to whatever OLD was (STREAMING / STALLED). `set_filter_chain()` returns `False`; `last_reload_error` exposes the inner `idle_reason`. Toggling enhancement can't brick a live cast. |

## 3. Architecture

### 3.1 `filter_chain.py` (NEW module)

```
FilterStage (Protocol)
  render() -> str          # returns ffmpeg -vf fragment; never empty
  _bind(input_url) (opt.)  # called by FilterChain before render() if present

NoopFilter            (built-in)
  render() -> "null"

SubtitleBurnIn(stream_index=0)   (built-in)
  _bind(input_url) — sets self._input_url
  render() -> "subtitles=<escaped_input_url>:si=<stream_index>"
    raises if _bind() wasn't called

FilterChain(stages=[NoopFilter()])
  render(input_url) -> str
    1. For each stage with _bind, call _bind(input_url)
    2. fragments = [stage.render() for stage in stages]
    3. If len > 1, drop any literal "null" (cleaner composition). Empty → ["null"].
    4. return ",".join(fragments)

_escape_for_subtitles_filter(path) -> str   (module-private helper)
```

### 3.2 `transcoder.py` refactor

Internal refactor to support two concurrent ffmpeg subprocesses during a swap.
**Public API is preserved bit-for-bit** so all 22 existing P2.2 unit tests pass
unchanged (this is the Task 1 gate).

```
Transcoder (public orchestrator — same surface as P2.2)
  state: TranscoderState         # aggregate of _current + _next; see §5
  idle_reason: Optional[str]     # for FAILED; cleared on successful reload
  exit_code: Optional[int]       # last reaped slot's exit code
  master_playlist: Path          # = _current.output_dir / "master.m3u8"
  output_dir: Path               # = _current.output_dir  (always _current's!)
  last_reload_error: Optional[str]  # NEW — set when set_filter_chain returned False

  start() -> None                # unchanged public behavior
  wait_until_ready(timeout) -> bool   # unchanged
  stop(drain_seconds) -> None    # tears down both slots if both exist
  set_filter_chain(chain) -> bool     # NEW — blocks; True=promoted, False=demoted

  _filter_chain: FilterChain     # NEW (constructor injected, default = FilterChain([NoopFilter()]))
  _current: _ProcessSlot         # always set once start() runs
  _next: Optional[_ProcessSlot]  # set during RELOADING
  _state_lock: threading.Lock
  _ready_event: threading.Event  # set on _current's first READY or FAILED
  _base_output_dir: Path         # the dir under which v1/, v2/, ... live
  _slot_counter: int             # monotonic v-suffix counter

_ProcessSlot (private inner — encapsulates one ffmpeg)
  output_dir: Path
  process: subprocess.Popen
  warming_timeout, stall_timeout, poll_interval: float
  sub_state: _SlotState          # SPAWNING / WARMING / READY / STREAMING / STALLED / FAILED / TERMINATING / TERMINATED
  idle_reason: Optional[str]
  exit_code: Optional[int]
  stderr_thread, poller_thread: threading.Thread
  stop_requested: threading.Event
  warming_started_monotonic: float
  last_seg_count: int
  last_new_seg_monotonic: float
  ready_event: threading.Event   # set on first READY or FAILED
  on_sub_state_change: Callable  # callback from constructor

  start(argv) -> None
  wait_until_ready(timeout) -> bool
  stop(drain_seconds) -> None    # q\n + drain + kill + reap + rmtree
  _is_ready_on_disk() -> (bool, int)
  _check_process_exit_locked() -> bool
  _stderr_reader_loop(), _watchdog_poller_loop()
```

**Refactor invariant:** every state field in the current Transcoder that's
tied to "this Popen" moves into `_ProcessSlot`. The Transcoder keeps only:
the public state aggregate, locks/events, slot refs, base output dir, the
active filter chain, the pending filter chain during a reload, and the
slot counter.

### 3.3 Output directory layout

```
<base_output_dir>/
    v1/                          ← _current.output_dir initially
        master.m3u8
        variant.m3u8
        seg_00000.ts, seg_00001.ts, ...
    v2/                          ← _next.output_dir during RELOADING
        master.m3u8
        variant.m3u8
        seg_00000.ts, ...
```

After successful promotion: `v1/` is `rmtree`'d; what was `v2/` is now the
`_current` slot's output_dir. Slot counter increments to 3 for the next reload.

`base_output_dir` is now the constructor parameter (renamed from
`output_dir` — see §4.1 migration). `Transcoder.output_dir` (the property)
returns `_current.output_dir`.

### 3.4 `set_filter_chain` flow

Single entry point; blocks until promotion or demotion.

```python
def set_filter_chain(self, chain: FilterChain) -> bool:
    with self._state_lock:
        # Guard rails (R1, R2, R3, R8)
        if self._state in (IDLE, FAILED, TERMINATING, TERMINATED):
            raise RuntimeError(...)
        if self._next is not None:
            raise RuntimeError("reload already in progress")
        if self._state not in (READY, STREAMING, STALLED):
            raise RuntimeError("set_filter_chain in unstable state ...")
        self._slot_counter += 1
        new_dir = self._base_output_dir / f"v{self._slot_counter}"
        self._next = _ProcessSlot(output_dir=new_dir, ...,
                                  on_sub_state_change=self._on_next_substate_change)
        argv = _build_argv(input_url, output_dir=new_dir, filter_chain=chain, accel=self._accel,
                           hls_segment_seconds=self._hls_segment_seconds)
        self._pending_filter_chain = chain
        self._set_state_locked(TranscoderState.RELOADING)

    self._next.start(argv)
    promoted = self._next.wait_until_ready(timeout=self._warming_timeout)

    with self._state_lock:
        # Caller may have called stop() during the wait
        if self._state in (TERMINATING, TERMINATED):
            next_to_stop = self._next
            self._next = None
        elif not promoted or self._next.sub_state == _SlotState.FAILED:
            # Demote
            self._last_reload_error = self._next.idle_reason or "reload_warming_timed_out"
            next_to_stop = self._next
            self._next = None
            self._pending_filter_chain = None
            self._set_state_locked(self._aggregate_current_state_locked())
            promoted = False
        else:
            # Promote
            next_to_stop = self._current
            self._current = self._next
            self._next = None
            self._filter_chain = self._pending_filter_chain
            self._pending_filter_chain = None
            self._last_reload_error = None
            self._set_state_locked(self._aggregate_current_state_locked())
            promoted = True

    # rmtree/kill outside the lock — slow on Windows
    if next_to_stop is not None:
        next_to_stop.stop()
    return promoted
```

`_aggregate_current_state_locked()` returns the matching `TranscoderState`
for `_current.sub_state` (e.g. `STREAMING` if `_current.sub_state ==
_SlotState.STREAMING`). Defined in §5.

2. Update the 3-4 tests in `test_transcoder_lifecycle.py` that compare

3. Run the full P2.2 test suite green before any P2.3 features land.

## 5. Updated state machine

| State | Means | Chromecast can fetch? |
|---|---|---|
| `IDLE` | Constructed; `start()` not yet called | NO |
| `SPAWNING` | `_current.sub_state == SPAWNING` | NO |
| `WARMING` | `_current.sub_state == WARMING` | NO |
| `READY` | `_current.sub_state == READY` | YES |
| `STREAMING` | `_current.sub_state == STREAMING` | YES |
| `STALLED` | `_current.sub_state == STALLED` | YES |
| **`RELOADING`** | `_current.sub_state ∈ {READY, STREAMING, STALLED}` AND `_next.sub_state ∈ {SPAWNING, WARMING, READY}` | **YES** (proxy still serves from `_current.output_dir`) |
| `FAILED` | `_current.sub_state == FAILED` AND (`_next is None` OR `_next.sub_state == FAILED`) | NO |
| `TERMINATING` | `stop()` called; both slots draining | NO |
| `TERMINATED` | All slots reaped + dirs deleted | NO |

`_aggregate_current_state_locked()` mapping (called when `_next is None`):

| `_current.sub_state` | `Transcoder.state` |
|---|---|
| SPAWNING | SPAWNING |
| WARMING | WARMING |
| READY | READY |
| STREAMING | STREAMING |
| STALLED | STALLED |
| FAILED | FAILED |
| TERMINATING | TERMINATING |
| TERMINATED | TERMINATED |

### 5.1 Critical invariants (the IDLE-race-lesson application)

1. **RELOADING is "cast still alive."** Proxy `_handle_cast` MUST NOT 503 it;
   popup polling MUST NOT classify it as "ended". Encoded in the table above
   and in the `state >= READY` predicate the proxy will gain in P2.4.
2. **`output_dir` always points at `_current`.** During RELOADING, before
   promotion, `transcoder.output_dir == _current.output_dir`. Verified by R12.
3. **`master_playlist` follows `output_dir`.** After promotion, both flip
   atomically under `_state_lock`. Verified by R13.
4. **If `_current.sub_state` becomes FAILED during RELOADING:**
   - If `_next.sub_state ∈ {SPAWNING, WARMING}`: state stays `RELOADING` —
     give NEW a chance to come up.
   - If `_next.sub_state == READY`: promote anyway; state → `STREAMING`;
     cast continues (OLD was dying, NEW took over). Verified by R9.
   - If both are FAILED: state → `FAILED`. Verified by R10.
5. **`set_filter_chain` is rejected** (raises `RuntimeError`) if called in
   `IDLE`, `SPAWNING`, `WARMING`, `FAILED`, `TERMINATING`, `TERMINATED`, or
   when a reload is already in progress. Only `READY` / `STREAMING` /
   `STALLED` can initiate a reload. Verified by R1, R2, R3, R8.

## 6. ffmpeg subtitles filter integration

Per context7 query 2026-05-15 against `/websites/ffmpeg_ffmpeg-all`.

### 6.1 Filter syntax

Form: `subtitles=<filename>[:option=value...]`

| Option | Alias | Default | Purpose |
|---|---|---|---|
| `filename` | `f` | (required) | Path to the file to demux subtitles from. For embedded streams, the same path as the input video works directly. |
| `stream_index` | `si` | 0 | Zero-based subtitle stream index inside the file. |
| `original_size` | — | unset | Original video size for font scaling — defaults are fine for our use. |
| `force_style` | — | unset | ASS style overrides — out of scope per kickoff prompt. |
| `charenc` | — | UTF-8 | Subtitle file encoding — out of scope. |
| `wrap_unicode` | — | on | Auto-line-wrap — leave default. |

For P2.3: `SubtitleBurnIn(stream_index=N).render()` returns:

```
subtitles=<escaped_input_url>:si=<N>
```

### 6.2 Path escaping rules

ffmpeg filtergraph escaping is two-level (per ffmpeg-all docs §filter
escaping). For our argv-style invocation (no shell, list of args via
`subprocess.Popen`), we only worry about **level 1** (option value) and
**level 2** (filtergraph syntax). Shell escaping is not in scope because we
never pass through a shell.

**Strategy for `_escape_for_subtitles_filter`:**

1. Wrap the path in single quotes — single quotes preserve `:`, `=`, `,` and
   any other filtergraph metacharacters as literal inside the option value.
2. Double any backslashes inside the quotes — `\` → `\\`.
3. If the path contains a literal single quote, splice it with `'\''` per the
   ffmpeg docs example (`'Crime d'\''Amour'`).

```python
def _escape_for_subtitles_filter(path: str) -> str:
    inner = path.replace("\\", "\\\\")
    inner = inner.replace("'", "'\\''")
    return f"'{inner}'"
```

Examples:

| Input path | Escaped output |
|---|---|
| `/tmp/sample.mkv` | `'/tmp/sample.mkv'` |
| `C:\Users\Abeds\AppData\Local\Temp\castbooster\<tok>\v1\input.mkv` | `'C:\\Users\\Abeds\\AppData\\Local\\Temp\\castbooster\\<tok>\\v1\\input.mkv'` |
| `/tmp/Crime d'Amour.mkv` | `'/tmp/Crime d'\''Amour.mkv'` |

Unit tests F5 and F6 (see §8) lock these forms.

### 6.3 New fatal pattern: `subtitle_stream_missing`

If `SubtitleBurnIn(stream_index=N)` targets a stream that doesn't exist
(`N` out of range, or the file has no sub streams), ffmpeg emits:

```
Stream specifier 's:0' in filtergraph description 'subtitles=...:si=0' matches no streams.
```

This pattern is NOT in P2.2's `_FATAL_PATTERNS`. P2.3 adds:

```python
(re.compile(r"Stream specifier.*matches no streams", re.I), "subtitle_stream_missing"),
```

This is the SPEC-LEVEL pre-emption of the Round 9 scope-drift trap: if we
didn't add this pattern up-front, the e2e-subs integration test
implementer would discover the gap, and either (a) silently widen
production fatal patterns, or (b) demote-via-warming-timeout (slower but
functional). We bake the right answer into the spec. Verified by R14.

### 6.4 libass dependency

`subtitles=` requires ffmpeg compiled with `--enable-libass`. The Gyan
Windows build vendored in P2.1 (`app/castbooster/bin/ffmpeg.exe`) includes
libass — verified by `ffmpeg -filters | grep subtitles` returning the
filter description.

Task 5 of the implementation plan (`SubtitleBurnIn` rollout) includes a
soft check that logs at WARNING if `subtitles` is not in `ffmpeg
-filters` output. Not a hard failure (some users may bring their own
ffmpeg via `CASTBOOSTER_FFMPEG`), just an actionable signal.

### 7.2 e2e-subs: `NoopFilter → SubtitleBurnIn` swap


The test points the Transcoder at `tmp_path/src/input.mkv` directly
(file URL, not HTTP — the proxy is not yet wired in P2.3). Note: the
`-t 30` makes it finite, but 30s is enough to observe the swap and reach
NEW's STREAMING. We accept a short clip because the e2e-subs test is
about subtitle filter syntax, not about reload concurrency.

**Walk:**

| Step | Action | Transcoder.state | _current.sub_state | _next.sub_state |
|---|---|---|---|---|
| 1 | Build fixture; start Transcoder with NoopFilter | SPAWNING → WARMING → READY → STREAMING | STREAMING | — |
| 2 | `set_filter_chain(FilterChain([SubtitleBurnIn(0)]))` | RELOADING | STREAMING | SPAWNING → WARMING |
| 3 | NEW ffmpeg argv contains `-vf` value: `subtitles='<escaped path>':si=0` | RELOADING | STREAMING | WARMING |
| 4 | NEW poller sees ≥ 2 segs in `v2/` | RELOADING | STREAMING | READY |
| 5 | Promote: kill OLD; rmtree `v1/`; swap refs | STREAMING | NEW (READY/STREAMING) | None |
| 6 | Assert `set_filter_chain` returned True | STREAMING | — | — |
| 7 | `stop()` | TERMINATING → TERMINATED | — | — |

**Boundary conditions to verify defined:**

- **libass missing:** vendored Gyan build has libass — verified by Task 5's soft check. If it's somehow missing, stderr matches `Error.*opening encoder` (existing P2.2 pattern) → NEW → FAILED → demote → return False. Defined.
- **Bad sub stream index:** P2.3 adds `subtitle_stream_missing` pattern (§6.3). Defined.
- **Subtitle path escape on Windows:** `_escape_for_subtitles_filter` wraps the path in single quotes + doubles backslashes (§6.2). Unit-tested by F5. Defined.
- **OLD's finite-source exit during NEW's WARMING:** OLD is finite (30s). If OLD's process exits cleanly (`exit_code == 0`) while NEW is still WARMING, the P2.2 clean-exit branch in `_check_process_exit_locked` keeps OLD in READY (via `_is_ready_on_disk()` check). State stays RELOADING. When NEW reaches READY, promote. **This branch exists in current production code** (added in P2.2 Round 9), and `_ProcessSlot` inherits it. Defined.
- **OLD exits with error during NEW's WARMING:** OLD → FAILED. Invariant #4 covers: state stays RELOADING. Promote when NEW becomes READY. Defined; tested by R9.
- **NEW exits with error during its WARMING:** NEW → FAILED. Demote path returns False; OLD still STREAMING (or finished cleanly via P2.2 branch). Defined; tested by R7.
